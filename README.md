# Focus Timer

Streamlit Cloud에서 실행할 수 있는 반응형 타이머입니다. Streamlit 외의 추가 라이브러리나 외부 웹 리소스를 사용하지 않습니다.

## 기능

- 타이머 및 스톱워치 모드
- 5·10·25·45·60분 프리셋과 직접 입력
- 시작, 일시정지, 초기화, 1분 추가
- 완료 알림음
- 모바일 및 데스크톱 반응형 UI
- 키보드 단축키: `Space` 시작/일시정지, `R` 초기화

## 로컬 실행

```bash
streamlit run main.py
```

## Streamlit Community Cloud 배포

저장소를 연결한 뒤 Main file path를 `main.py`로 지정합니다.
